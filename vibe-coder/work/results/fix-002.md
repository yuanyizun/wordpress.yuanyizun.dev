# Results: Fix the layout issues in multiple pages

> AI-managed only — humans do not edit this file.

## Summary

Restored visible primary CTA and footer link text (WordPress global-styles link colour was beating Tailwind utilities) and pinned the footer on short pages with a body flex shell. Theme 0.4.2; layout audit re-run.

## Findings

- **Root cause (invisible CTAs / footer links):** WordPress global-styles emits unlayered `a:where(:not(.wp-element-button)) { color: … }`. That beats Tailwind `@layer utilities` (including `text-inverse`), so primary-coloured text sat on `bg-primary` buttons and footer chrome — labels looked blank. `theme.json` had set link text to primary, which made it worse; inherit alone is not enough because the unlayered `a` rule still overrides layered utilities.
- **Solution:** Set link colour to `inherit` in `theme.json`, and bridge `a.text-*` in unlayered `overrides.css` so utility colours win on anchors. Prefer `text-inverse` / `!text-inverse` on primary CTAs going forward.
- **Root cause (cream below footer):** Short pages left the footer mid-viewport; Playwright full-page shots showed page background under the footer.
- **Solution:** `body` as column flex (`min-height: 100dvh`) with `main { flex: 1 0 auto }`.
