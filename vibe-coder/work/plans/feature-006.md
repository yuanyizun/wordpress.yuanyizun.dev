# Plan: Generate pure HTML static pages from design

> AI-managed only — humans do not edit this file.

## Summary

Produce pixel-faithful static HTML pages for all eight Still Cup Pencil artboards in `vibe-coder/resource/documents/static_html_design`, styled with **Tailwind CSS v4** (same Still Cup `@theme` tokens as the theme), using exact copy, typography, colours, and coordinates from `Still-Cup-Design.pen` / `specs.md`.

## Goals

- One static HTML file per designed artboard (desktop + mobile)
- Tailwind utilities only for layout/type/colour (no hand-rolled page CSS)
- Shared `@theme` tokens matching Still Cup (`bg-page`, `text-primary`, `font-display`, …)
- Controls (inputs, selects, buttons, swatches, quantity) match drawn sizes and labels
- Unsplash reference images as used in the design master
- Index page to open each screen; committed built `css/app.css`

## Recommended approach (decision)

| Option | Verdict |
|--------|---------|
| **A. Fixed artboard HTML + Tailwind v4 utilities (chosen)** — each page is a 1440 or 390 canvas; absolute positions via arbitrary utilities; local Tailwind build with Still Cup `@theme` | **Yes** — pixel match + required Tailwind stack |
| B. Custom CSS / tokens.css only | No — must use Tailwind |
| C. Five responsive pages with media queries only | No — would interpolate between artboards and drift from exact positions |
| D. Import theme `app.css` from WordPress theme | No — static pack should be self-contained |

## Implementation steps

1. Scaffold `static_html_design/` with Tailwind v4 (`package.json`, `src/css/app.css`, build → `css/app.css`).
2. Build desktop pages: home, product, shop, bag, checkout — absolute layout via Tailwind utilities from specs.
3. Build mobile pages: home, product, checkout — absolute layout via Tailwind utilities from specs.
4. Wire shared chrome, forms, selects, swatches, and image URLs from the design master.
5. Run `npm run build`; spot-check against Pencil screenshots / specs.
6. Write results, sync catalog, mark feature done.
