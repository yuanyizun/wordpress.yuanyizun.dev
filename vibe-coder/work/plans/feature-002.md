# Plan: Still Cup theme foundation — design tokens and site chrome

> AI-managed only — humans do not edit this file.

## Summary

Create and activate a minimal Still Cup WordPress theme that encodes the design system (tokens, typography, breakpoint) and shared site chrome (announcement, header/nav/menu, footer). No product catalogue, page templates beyond a thin shell, or commerce configuration in this feature.

## Implementation steps

1. **Theme scaffold** — Add `wp-content/themes/still-cup/` (custom theme, not a Twenty* child, unless a stable parent is clearly better for Woo blocks). Include `style.css`, `functions.php`, `theme.json` (where useful for block editor colours/fonts), `index.php`, `header.php`, `footer.php`.
2. **Design tokens** — CSS custom properties from specs.md: page bg `#F6F2EB`, primary `#243A31`, hero `#E9E0D3`, story `#DDE2D7`, borders `#CFCFC4`, order summary `#E9E8DF`, muted `#59645D`, swatches Sand/Olive/Chalk. Gutters 64 / 20; content max aligned to 1312 desktop / 350 mobile artboard spans. Breakpoint **1024px**.
3. **Typography** — Load **Newsreader** (wordmark/headings) and **Inter** (UI/body) via `wp_enqueue` (Google Fonts or self-hosted if preferred locally). Base body line-height ~1.5 per decisions.md; mobile inputs ≥16px.
4. **Announcement bar** — Full-bleed `#243A31` strip; shipping/messaging placeholder editable later (theme mod or simple option).
5. **Header** — Wordmark → home; desktop nav (Shop all, Mugs, Cups, Tumblers — Cups included per decisions.md); utility: Search, Account, Bag with count placeholder. Below 1024px: hamburger + keyboard-operable panel with visible close and focus return.
6. **Footer** — Dark primary band; placeholder links for supporting pages (story, care, shipping, privacy, terms, contact) without building those pages yet.
7. **Activate & smoke** — Activate theme on staging; verify homepage chrome at desktop and ≤1023px; no horizontal overflow at 320px for the shell.
8. **UI docs** — Record chrome components under `vibe-coder/resource/ui/` after implementation.
