# Plan: Still Cup page templates — Home, Shop, Product, Bag, Checkout

> AI-managed only — humans do not edit this file.

## Summary

Extend the `still-cup` theme with front-end templates that match the Pencil artboards for Home, Shop, Product, Bag, and Checkout (plus a thin supporting `page.php` and order-result styling). Reuse feature-002 chrome/tokens. Do not load the six-product catalogue or configure shipping/payments in this feature.

## Implementation steps

1. **Template map** — Add theme files: `front-page.php` (or block template + patterns), `woocommerce.php` / Woo overrides under `woocommerce/`, `page.php`, and styles in `assets/css/` (split by area if needed). Prefer WooCommerce template overrides over forking core.
2. **Home** — Block-editable sections: announcement already in chrome; hero (`#E9E0D3`, CTA), benefits strip, featured products grid (3 col desktop / 2 mobile), story band (`#DDE2D7`). Hero: text before image below 1024px. Wire featured products via Woo “featured” or a block query so owners edit without PHP.
3. **Shop** — Archive/product loop: filters All cups / Mugs / Cups / Tumblers; sort Featured / price low–high / high–low / Latest; active filter + reset; product cards (image, name, price, finishes summary) → single product. Six posts per page; columns 3 / 2 / 1 by width. Hide decorative pagination when all results fit page 1.
4. **Product** — Gallery (desktop side-by-side; mobile swipe + accessible controls later if time); variation UI for Finish (swatches + text labels + selected outline) and Capacity; price/stock/qty/add-to-bag; details as expanded rows desktop / accordions mobile. Defaults: Sand when purchasable; Everyday Mug 300 ml when that product exists. Single-capacity products show capacity as text.
5. **Bag** — Cart template: line items, qty ± / remove, summary panel (`#E9E8DF`); mobile stacks image/details above totals; empty state with Shop cups CTA. Shipping estimate messaging structural only (rates in later feature).
6. **Checkout** — Two-column ≥1024 (form left, summary right); mobile summary before form. Separate State/Postcode, optional Address 2; billing same-as-shipping option. Payment UI left to gateway plugins (schematic only). Style order-received / thank-you.
7. **Supporting pages** — Shared `page.php` using chrome + readable long-copy (~1.5 line-height); no unique HF artboards.
8. **Assets & docs** — Enqueue template CSS; document patterns/components under `vibe-coder/resource/ui/still-cup/`. Smoke-test key URLs on staging.
