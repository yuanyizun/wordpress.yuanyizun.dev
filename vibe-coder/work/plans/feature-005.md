# Plan: Add Playwright script and report generator

> AI-managed only — humans do not edit this file.

## Summary

Add a root folder `layout-audit/` with a Playwright layout script. `node audit.mjs` (run from that folder) screenshots each configured route at each viewport and writes `layout-report/report.html` plus the PNGs.

## Goals

- One command produces a visual layout report of the live staging site
- Base URL, route list, and viewports live in their own files so they can change without editing the runner
- Generated images and HTML stay out of git

## Recommended approach (decision)

| Option | Verdict |
|--------|---------|
| **A. `playwright` library + `audit.mjs` (chosen)** — same shape as the brief’s sample, config split into three modules | **Yes** — matches `node audit.mjs` and the sample loop |
| B. `@playwright/test` spec + `npx playwright test` | No — different command and reporter than the brief |
| C. Script inside `wp-content/themes/still-cup/` | No — theme package is for Tailwind; this audits the site, not the theme build |

Stack:

- New folder at the site root: `layout-audit/`
- Dependency: `playwright` (Chromium only). Entry stays `audit.mjs` so Node treats it as ESM without `"type": "module"`
- Config modules next to the entry, each a named export:
  - `base-url.mjs` → `BASE_URL`
  - `routes.mjs` → `ROUTES`
  - `viewports.mjs` → `VIEWPORTS`
- Output directory stays inside the runner as `./layout-report` (relative to the folder you run from), matching the sample. It is not a fourth config file.

## Implementation steps

1. **Scaffold `layout-audit/`**
   - `package.json`: private package, dependency `playwright`. No extra npm script is required; the command is `node audit.mjs`.
   - Do not add Playwright to the Still Cup theme `package.json`.

2. **Config files**
   - `base-url.mjs`: `export const BASE_URL = 'https://wordpress.yuanyizun.dev';` (no trailing slash).
   - `viewports.mjs`: the sample pair — desktop `1440×900`, mobile `375×812`. Those sit on either side of the theme’s 1024px desktop breakpoint.
   - `routes.mjs`: published storefront paths only (permalink structure `/%postname%/`):
     - `/`
     - `/shop/`
     - `/product/placeholder-cup/`
     - `/cart/`
     - `/checkout/`
     - `/our-story/`
   - Do not seed `/about` or `/contact`. Those paths are in the sample only; this site has no such pages. Footer targets `/care-guide/`, `/shipping-returns/`, `/contact/`, `/privacy/`, and `/terms/` are not published. Skip `sample-page` and `/my-account/` (login wall).

3. **`audit.mjs`**
   - Import `chromium` from `playwright`, `fs`, `path`, and the three config exports.
   - `mkdir` `layout-report`, launch headless Chromium, one page, loop routes × viewports.
   - Slug: `/` → `home`; otherwise strip slashes to underscores (`/shop/` → `shop`, `/product/placeholder-cup/` → `product_placeholder-cup`).
   - `setViewportSize`, `goto` `${BASE_URL}${route}` with `waitUntil: 'networkidle'` and a 30s timeout, full-page PNG named `{slug}-{viewport}.png`.
   - If one navigation fails, record the error in the HTML and continue. One bad URL must not skip the rest of the report.
   - Write `layout-report/report.html` (title, route, viewport size, image or error) and log the report path. Close the browser in a `finally`.

4. **Ignore generated output**
   - Root `.gitignore` already ignores `node_modules/`. Add `layout-audit/layout-report/` so PNGs and `report.html` are not committed.

5. **Install browsers once**
   - From `layout-audit/`: `npm install`, then `npx playwright install chromium`.

## Notes & Decisions

- Run from `layout-audit/` so `node audit.mjs` and `./layout-report` both resolve. `node layout-audit/audit.mjs` from the repo root would write the report at the repo root instead; do not document that as the command.
- `networkidle` matches the sample. WooCommerce can keep connections open; the 30s timeout plus per-route catch keeps a hung cart or checkout from aborting the run.
- Cart and checkout screenshots are the empty-cart / empty-checkout states. This script does not add a product to the bag.
- Routes are path strings joined onto `BASE_URL`. Keep a leading slash. Trailing slashes match WordPress permalinks.
- When the catalogue replaces Placeholder Cup, update `routes.mjs` only.
