# Still Cup — developer handover

Version 1.3 · 12 November 2026 · Fictional practice project

Build an editable WordPress + WooCommerce shop for an Australian cup brand. This package contains the customer brief, native editable Pencil design, exact design specifications, delivery instructions and planned acceptance criteria. It contains no implemented website or credentials.
