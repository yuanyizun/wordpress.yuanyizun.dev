# Plan file rules (agent)

Plans under `vibe-coder/work/plans/` are **AI-only**. Humans never edit them.

- Create from `vibe-coder/templates/plan.md` when the brief’s rules require a plan
- Keep Summary, Implementation steps, Files to change, Test plan, and Notes & Decisions current
- After saving the plan file:
  `npx vibe catalog sync {id}`
- Never hand-edit `vibe-coder/work/plans/catalog.md` (see `vibe-coder/rules/catalog.md`)
